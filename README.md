# اپلیکیشن فیدل – نسخه اولیه

این پروژه یک شروع واقعی برای اپلیکیشن چندسکویی Flutter است و برای Android و iOS طراحی شده است.

## امکانات موجود در نمونه
- رابط فارسی و راست‌چین
- فهرست ۱۰ مدل در دو سری ECONOMY و PLUS
- انتخاب ابعاد و نمایش قیمت‌های واردشده از کاتالوگ‌های ارائه‌شده
- صفحه گفت‌وگوی نوشتاری نمونه
- صفحه سفارش‌ها (فعلاً نمایشی)

## مواردی که هنوز عملیاتی نیستند
- ثبت سفارش و سبد خرید واقعی
- درگاه پرداخت و تأیید پرداخت
- ورود/ثبت‌نام و پروفایل مشتری
- اتصال به سرور و پنل مدیریت
- پاسخ‌گویی هوشمند واقعی (چت فعلی نمایشی است)
- تصاویر اصلی محصولات و جزئیات کامل مدل‌ها

قیمت‌ها به میلیون تومان وارد شده‌اند و باید پیش از انتشار نهایی توسط مسئول فروش تأیید شوند. قیمت برای سایزهایی که در کاتالوگ موجود نبوده، عمداً نمایش داده نمی‌شود.

## اجرای پروژه
Flutter SDK را نصب کنید، سپس در پوشه پروژه اجرا کنید:

```bash
flutter pub get
flutter run
```

برای خروجی اندروید:
```bash
flutter build apk --release
```

برای خروجی iOS به macOS و Xcode نیاز است:
```bash
flutter build ipa --release
```

انتشار در Google Play و App Store نیازمند حساب توسعه‌دهنده، امضای برنامه و تکمیل الزامات فروشگاه‌ها است.
